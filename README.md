# Symbios

**Verifierad affärsproblemlösning där AI är motorn.**

Symbios bygger en strukturerad förståelse av ett företag, undersöker marknaden, tar fram testbara konkurrensfördelar och hjälper användaren vidare mot den mest värdefulla nästa åtgärden.

## Status

Aktuell baslinje: **Company Intelligence v0.6.1**

Kärnflöde:

1. Adaptiv företagsintervju
2. Company Genome
3. Confidence och kvalitetskontroll
4. Lokal eller regional marknadsresearch
5. Opportunity + Edge Engine
6. Testbar nästa åtgärd

## Starta på Windows

Kör `START_SYMBIOS.bat` för lokalt demoläge eller `START_WITH_INTERNET_WINDOWS.bat` för webbresearch med en OpenAI API-nyckel.

## Tester

```bash
python scripts/run_tests.py
```

Projektet använder endast Python-standardbiblioteket i den lokala kärnan.
